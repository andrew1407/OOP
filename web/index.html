Shape Editor

The shape-painting app from the OOP labs, running in your browser. It is a Win32 program compiled from its own C++ sources to WebAssembly.

Shape editor · lab 5

Pick a tool on the toolbar or in Objects and drag on the canvas: point, line, rectangle, ellipse, a line with circles at its ends, or a cube. Every shape you draw is appended to shapes.txt and to the modeless Shape list window (Help → Shape list), where you can select a shape to highlight it in red, or delete it. File → Read file loads the shapes in shapesRead.txt onto the canvas and into the list.

How it runs. The lab's own sources (Lab5.cpp, my_editor.cpp, my_table.cpp, editor.cpp, shape.cpp, toolbar.cpp) are compiled to WebAssembly with emscripten, including wWinMain and its message loop, which waits on the page through Asyncify. The Win32 calls go to a small shim (web/win32): windows, messages and dialogs run in C++, and GDI drawing goes to the canvas with the same pens, brushes and R2_NOTXORPEN raster mode. Menus, the toolbar, dialogs and strings come from the lab's .rc files and bitmaps. shapes.txt and shapesRead.txt live in the module's memory file system in the lab's text format.

The client area is white, as in the Windows original. Drawing works with a mouse, a pen or a finger.
